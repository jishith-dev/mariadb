# Mariadb / MySQL

MySQL-compatible database client for the Zen programming language.

The current implementation uses MariaDB Connector/C through a native C bridge. Zen code interacts with the database through a simple typed API without exposing MySQL or MariaDB internal structures.

## Features

- MySQL/MariaDB-compatible database connections
- SQL query execution
- SELECT result handling
- Row access by column index
- `int`, `long`, `double`, and `string` value access
- Prepared statements
- Parameter binding
- Transactions
- Affected-row count
- Last inserted ID
- Database error reporting
- Explicit resource cleanup
- Native C bridge
- Portable native `.c` source

## Requirements

The current native implementation requires:

- Zen
- MariaDB Connector/C
- A running MySQL-compatible database server

The native bridge currently uses:

```c
#include <mariadb/mysql.h>
```

and links against:

```text
-lmariadb
```

The package's `native/mysql.c` is compiled by Zen for the target platform.

The MariaDB client library must be available on the target system.

## Installation

Install the package using the Zen package manager:

```text
zen install mysql
```

Then import the API:

```zen
import (
  Database,
  Result,
  Row,
  Statement,
  connect
) from "mysql"
```

## Connecting

Use `connect()` to create a database connection.

### Signature

```text
connect(
  string host,
  string user,
  string password,
  string database,
  int port
) Database
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `host` | `string` | Database server address |
| `user` | `string` | Database username |
| `password` | `string` | Database password |
| `database` | `string` | Database name |
| `port` | `int` | Database server port |

### Example

```zen
Database db = connect(
  "127.0.0.1",
  "root",
  "",
  "test",
  3306
)

if (!db.ok()) {
  screen(db.error())
  os.exit(1)
}

screen("connected")
```

## Database API

`Database` represents an active database connection.

### `ok()`

```text
ok() bool
```

Checks whether the database connection is valid.

```zen
if (!db.ok()) {
  screen(db.error())
  os.exit(1)
}
```

### `query()`

```text
query(string sql) int
```

Executes an SQL statement.

A return value of `0` indicates success.

```zen
int code = db.query(
  "CREATE TABLE users (id INT, name TEXT, age INT)"
)

if (code != 0) {
  screen(db.error())
}
```

It can be used for statements such as:

- `CREATE`
- `INSERT`
- `UPDATE`
- `DELETE`
- `SELECT`
- `ALTER`
- `DROP`

and other SQL statements supported by the database server.

### `error()`

```text
error() string
```

Returns the current database error message.

```zen
if (db.query(
  "SELECT unknown_column FROM users"
) != 0) {
  screen(db.error())
}
```

### `affectedRows()`

```text
affectedRows() long
```

Returns the number of rows affected by the most recent query.

```zen
db.query(
  "UPDATE users SET age = 22 WHERE id = 2"
)

long count = db.affectedRows()

screen(count)
```

### `insertId()`

```text
insertId() long
```

Returns the ID generated by the most recent insert when the database generates an insert ID.

```zen
db.query(
  "INSERT INTO users (name, age) VALUES ('Jishith', 21)"
)

long id = db.insertId()

screen(id)
```

### `result()`

```text
result() Result
```

Creates a `Result` from the result of the most recent result-producing query.

Use it after executing a `SELECT` query.

```zen
int code = db.query(
  "SELECT id, name, age FROM users"
)

if (code != 0) {
  screen(db.error())
  os.exit(1)
}

Result result = db.result()
```

### `begin()`

```text
begin() int
```

Starts a database transaction.

```zen
int code = db.begin()

if (code != 0) {
  screen(db.error())
}
```

### `commit()`

```text
commit() int
```

Commits the current transaction.

```zen
int code = db.commit()

if (code != 0) {
  screen(db.error())
}
```

### `rollback()`

```text
rollback() int
```

Rolls back the current transaction.

```zen
int code = db.rollback()

if (code != 0) {
  screen(db.error())
}
```

### `prepare()`

```text
prepare(string sql) Statement
```

Creates a prepared SQL statement.

```zen
Statement stmt = db.prepare(
  "INSERT INTO users (id, name, age) VALUES (?, ?, ?)"
)
```

### `close()`

```text
close() void
```

Closes the database connection.

```zen
db.close()
```

## Result API

`Result` represents the result set returned by a query.

### `columnCount()`

```text
columnCount() int
```

Returns the number of columns in the result.

```zen
screen(result.columnCount())
```

For:

```sql
SELECT id, name, age FROM users
```

the result is:

```text
3
```

### `rowCount()`

```text
rowCount() long
```

Returns the number of rows in the result.

```zen
screen(result.rowCount())
```

### `next()`

```text
next() Row
```

Returns the next row from the result.

When there are no more rows, the returned `Row` is invalid.

```zen
Row row = result.next()

while (row.valid()) {
  screen(row.getInt(0))
  screen(row.getString(1))
  screen(row.getInt(2))

  row.close()

  row = result.next()
}
```

### `close()`

```text
close() void
```

Releases the result.

```zen
result.close()
```

## Row API

`Row` represents one row returned by a query.

Column indexes are zero-based.

For:

```sql
SELECT id, name, age FROM users
```

the indexes are:

| Index | Column |
|---:|---|
| `0` | `id` |
| `1` | `name` |
| `2` | `age` |

### `valid()`

```text
valid() bool
```

Checks whether the row contains valid data.

```zen
Row row = result.next()

while (row.valid()) {
  screen(row.getString(1))

  row.close()
  row = result.next()
}
```

### `getString()`

```text
getString(int index) string
```

Returns a column as a `string`.

```zen
string name = row.getString(1)

screen(name)
```

### `getInt()`

```text
getInt(int index) int
```

Returns a column as an `int`.

```zen
int id = row.getInt(0)

screen(id)
```

### `getLong()`

```text
getLong(int index) long
```

Returns a column as a `long`.

```zen
long value = row.getLong(0)

screen(value)
```

### `getDouble()`

```text
getDouble(int index) double
```

Returns a column as a `double`.

```zen
double value = row.getDouble(2)

screen(value)
```

### `close()`

```text
close() void
```

Releases the current row wrapper.

```zen
row.close()
```

## Prepared Statements

Prepared statements allow SQL parameters to be supplied separately from the SQL string.

Create a statement with `db.prepare()`:

```zen
Statement stmt = db.prepare(
  "INSERT INTO users (id, name, age) VALUES (?, ?, ?)"
)
```

Parameters are zero-based:

```text
0 → first ?
1 → second ?
2 → third ?
```

## Statement API

### `bindInt()`

```text
bindInt(int index, int value) int
```

Binds an `int` value.

```zen
stmt.bindInt(0, 4)
```

### `bindLong()`

```text
bindLong(int index, long value) int
```

Binds a `long` value.

```zen
long id = 100000

stmt.bindLong(0, id)
```

### `bindDouble()`

```text
bindDouble(int index, double value) int
```

Binds a `double` value.

```zen
double price = 99.50

stmt.bindDouble(1, price)
```

### `bindString()`

```text
bindString(int index, string value) int
```

Binds a `string` value.

```zen
stmt.bindString(1, "Prepared")
```

### `execute()`

```text
execute() int
```

Executes the prepared statement.

```zen
int code = stmt.execute()

if (code != 0) {
  screen(db.error())
}
```

### `affectedRows()`

```text
affectedRows() long
```

Returns the number of rows affected by the prepared statement.

```zen
screen(stmt.affectedRows())
```

### `close()`

```text
close() void
```

Releases the prepared statement.

```zen
stmt.close()
```

## Transactions

A transaction can be used to group multiple database operations.

### Commit Example

```zen
int code = db.begin()

if (code != 0) {
  screen(db.error())
  os.exit(1)
}

code = db.query(
  "INSERT INTO users (id, name, age) VALUES (10, 'Alice', 20)"
)

if (code != 0) {
  db.rollback()
  screen(db.error())
  os.exit(1)
}

code = db.query(
  "INSERT INTO users (id, name, age) VALUES (11, 'Bob', 21)"
)

if (code != 0) {
  db.rollback()
  screen(db.error())
  os.exit(1)
}

code = db.commit()

if (code != 0) {
  screen(db.error())
}
```

### Rollback Example

```zen
int code = db.begin()

if (code != 0) {
  screen(db.error())
  os.exit(1)
}

code = db.query(
  "INSERT INTO users (id, name, age) VALUES (20, 'Temporary', 30)"
)

if (code != 0) {
  db.rollback()
  screen(db.error())
  os.exit(1)
}

db.rollback()
```

The insert is discarded by the rollback.

## Prepared Statement Example

```zen
Statement stmt = db.prepare(
  "INSERT INTO users (id, name, age) VALUES (?, ?, ?)"
)

stmt.bindInt(0, 4)
stmt.bindString(1, "Prepared")
stmt.bindInt(2, 25)

int code = stmt.execute()

if (code != 0) {
  screen(db.error())
} else {
  screen(stmt.affectedRows())
}

stmt.close()
```

## Complete Example

```zen
import (
  Database,
  Result,
  Row,
  Statement,
  connect
) from "mysql"


Database db = connect(
  "127.0.0.1",
  "root",
  "",
  "test",
  3306
)

if (!db.ok()) {
  screen(db.error())
  os.exit(1)
}

screen("connected")


int code = db.query(
  "CREATE TABLE IF NOT EXISTS users (id INT, name TEXT, age INT)"
)

if (code != 0) {
  screen(db.error())
  db.close()
  os.exit(1)
}


code = db.query(
  "INSERT INTO users (id, name, age) VALUES (2, 'Zen', 21)"
)

if (code != 0) {
  screen(db.error())
  db.close()
  os.exit(1)
}

screen(db.affectedRows())


code = db.query(
  "SELECT id, name, age FROM users"
)

if (code != 0) {
  screen(db.error())
  db.close()
  os.exit(1)
}


Result result = db.result()

screen(result.columnCount())
screen(result.rowCount())


Row row = result.next()

while (row.valid()) {
  screen(row.getInt(0))
  screen(row.getString(1))
  screen(row.getInt(2))

  row.close()

  row = result.next()
}

result.close()


code = db.begin()

if (code != 0) {
  screen(db.error())
  db.close()
  os.exit(1)
}

code = db.query(
  "INSERT INTO users (id, name, age) VALUES (3, 'Transaction', 30)"
)

if (code != 0) {
  db.rollback()
  screen(db.error())
  db.close()
  os.exit(1)
}

db.rollback()


Statement stmt = db.prepare(
  "INSERT INTO users (id, name, age) VALUES (?, ?, ?)"
)

stmt.bindInt(0, 4)
stmt.bindString(1, "Prepared")
stmt.bindInt(2, 25)

code = stmt.execute()

if (code != 0) {
  screen(db.error())
} else {
  screen(stmt.affectedRows())
}

stmt.close()


db.close()

screen("closed")
```

## Native Backend

The package uses a small C bridge between Zen and MariaDB Connector/C.

Zen does not directly handle:

```text
MYSQL*
MYSQL_RES*
MYSQL_ROW
MYSQL_STMT*
```

The native layer keeps those database structures on the C side and exposes opaque handles to Zen.

The general architecture is:

```text
Zen application
      |
      v
lib.zen
      |
      v
native/mysql.c
      |
      v
MariaDB Connector/C
      |
      v
MySQL/MariaDB server
```

This keeps database-specific native structures outside the Zen program.

## Current Backend

The current version is implemented using MariaDB Connector/C.

It is intended to communicate with MySQL-compatible database servers, but the package is not an official MySQL or MariaDB product.

## Resource Management

Database resources should be explicitly closed when they are no longer needed.

Recommended order:

```text
Statement → close()
Result    → close()
Database  → close()
```

For example:

```zen
stmt.close()
result.close()
db.close()
```

## Error Handling

Database operations return integer status codes.

Check the return value before continuing when an operation is expected to succeed.

```zen
int code = db.query(
  "INSERT INTO users VALUES (1, 'Zen', 21)"
)

if (code != 0) {
  screen(db.error())
  os.exit(1)
}
```

For connection failures:

```zen
Database db = connect(
  "127.0.0.1",
  "root",
  "",
  "test",
  3306
)

if (!db.ok()) {
  screen(db.error())
  os.exit(1)
}
```

## Notes

- SQL is executed by the database server.
- SQL syntax and supported features depend on the connected database server.
- Prepared-statement parameter indexes are zero-based.
- Result column indexes are zero-based.
- The current native backend depends on MariaDB Connector/C.
- The package does not expose the underlying MariaDB/MySQL C structures to Zen.
- Always close database resources when finished with them.
